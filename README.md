# AERONAV HAHO — Release Point Planner & Tactical Navigator

Applicazione web progressiva (**PWA**) installabile su smartphone e pronta per la pubblicazione diretta su **GitHub Pages** o qualsiasi hosting statico HTTPS.

## Aggiornamento Layout Mobile (v6)
* **Barra superiore adattiva su 2 righe su smartphone**: tutti i pulsanti (`MAPPA`, `DIP / ALT (5)`, `PLANNER`, `INSTALLA`, `TAP DIP`, `HDG UP`, `GPS`, `SIM`) rientrano interamente nella larghezza dello schermo senza tagli laterali o testo spezzato su più righe.
* **Pulsanti azione `MAPPA`, `DEM` e `ATTIVA` a larghezza piena** nella scheda `DIP / ALT (5)`.
