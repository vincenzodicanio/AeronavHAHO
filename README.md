# AERONAV HAHO — Release Point Planner & Tactical Navigator

Applicazione web progressiva (**PWA**) installabile su smartphone e pronta per la pubblicazione diretta su **GitHub Pages** o qualsiasi hosting statico HTTPS.

## Flusso Selezione e Attivazione DIP Alternativi (v5)
1. **Scelta DIP sulla Mappa**: Toccando un marker DIP esistente sulla mappa (o selezionando un nuovo punto con **`TAP DIP`** / **`MAPPA`**), l'applicazione torna automaticamente alla scheda **`DIP / ALT (5)`** evidenziando lo slot scelto con coordinate MGRS e quota DEM aggiornate.
2. **Attivazione e Ricalcolo**: Premendo **`ATTIVA`** sulla riga desiderata, l'applicazione torna immediatamente alla schermata **`MAPPA`** con il DIP attivato, tutti i parametri di navigazione ricalcolati (distanza, rotta, ETE, efficienza richiesta) e auto-zoom sulla nuova traccia.
